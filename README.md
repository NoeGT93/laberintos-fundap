# Laberintos FUNDAP

Generador de laberintos imprimibles (niveles 1, 2 y 3) en forma cuadrada, circular, hexagonal, triangular y de corazón.
Cada laberinto tiene un inicio y 3 salidas (A, B, C) con sus respuestas; solo la salida correcta conecta con el inicio.
Exporta a PDF vectorial (A4) y SVG con líneas editables para Illustrator.

Es un solo archivo: abre `index.html` en el navegador, o publícalo con GitHub Pages (Settings → Pages → rama `main`).
